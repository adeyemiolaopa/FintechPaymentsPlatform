# Unknown provider reference

Confirm provider, file hash, business date, row number and raw-row hash. Search by client reference and check Payment event lag and provider-reference format changes. Requery the provider without changing internal state. If the transaction belongs to another merchant or file, request provider correction. If an internal transfer is missing, investigate the Payment/rail submission lifecycle and restore events through controlled replay. Never create a Payment or ledger posting solely from a settlement row.
