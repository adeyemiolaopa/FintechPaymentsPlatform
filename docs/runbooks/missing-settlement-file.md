# Missing settlement file

Verify the provider-specific expected delivery schedule, local business date, cutoff, weekend and holiday rules before alerting. Check ingestion logs, storage permissions, object hash, API upload attempts and worker health. Ask the provider for a resend without treating the absence as failed transfers. Reimport by raw hash; the same bytes must map to the same logical file. Escalate after the contractual delivery deadline and track internal successful transfers as pending settlement evidence.
