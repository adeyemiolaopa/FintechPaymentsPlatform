# Reconciliation exception spike

Group by provider, code, file hash, business date and deployment time, not by customer identifiers. Check provider outage or changed settlement schema, reference formatting, internal deployment bugs, consumer lag, and duplicate-file delivery. Compare row counts and per-currency totals. Pause unsafe automated recovery if contradictions appear, preserve files and observations, and avoid bulk closing exceptions. Reprocess idempotently only after the root cause is understood.
